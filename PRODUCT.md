# Tenix-ChaeDiew — product

**What it is.** A macOS screenshot, annotation and OCR tool for one organisation's staff, with its own licence keys. Powered by Panupong Nijjaboon.

**Who uses it, and where.** Staff capturing a screen many times a day: support, QA, documentation, security reviewers. They work in bright and dim offices, usually with other windows open behind the editor, and want the picture to lead and the tools to disappear.

**Mode (Impeccable).** Operate: the user completes a task. Scanability, consistency and keyboard speed outrank expression. The brand lives in precise details (palette, wordmark, one accent), not in decoration.

**Anchors.** Shottr (behaviour and keyboard model), native macOS conventions (menus, ⌘ shortcuts, traffic lights in the title bar).

**Principles.**
1. The screenshot is the hero. Chrome is dark and quiet so any picture reads correctly against it.
2. Everything reachable by keyboard has its key in the tooltip and in Help ▸ Keyboard Shortcuts.
3. One accent (#1FA0FF) means "active / primary". Never decorative.
4. Show the result while it is being changed (colour, backdrop, text styling apply live; nothing waits for "OK").
5. Thai and English are equal citizens: every string has both.
6. Nothing leaves the machine except uploads the user configures.
