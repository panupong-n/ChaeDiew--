## 6) รอบที่ 5 — "ใส่คีย์แล้วจบ" (เวอร์ชัน 0.3.0)
เจ้าของอนุมัติ: คีย์ `TXCD1-…` ที่ลายเซ็นถูกและยังไม่หมดอายุ = **Licensed ทันที** ไม่ต้องใช้รหัสเปิดใช้งาน `TXAC1-…` (ไม่มีเซิร์ฟเวอร์ ใช้ในทีมภายใน) รูปแบบคีย์/รหัสและ `src/public-key.js` ไม่เปลี่ยน

**ไฟล์ที่แก้**
- `src/license.js` — `LicenseManager` รับ `requireActivation` (ค่าเริ่มต้น `false`); `status()` คืน `licensed` ทันทีหลัง `verifyKey` ผ่าน; โหมดผูกเครื่องยังอยู่เมื่อตั้ง `true`
- `renderer/license.js` — Licensed: ซ่อนช่องกรอก/Activate/Paste เหลือ "ลบไลเซนส์", ไม่แสดง Seats และรหัสเครื่อง; ช่วงทดลอง/หมดทดลอง: ไม่แสดงรหัสเครื่อง ป้ายช่องกรอกเป็น "คีย์ไลเซนส์"; "needsActivation" ไม่มีบรรทัด Free trial
- `src/strings.js` — เพิ่ม `'License key': 'คีย์ไลเซนส์'`
- `test/license.test.js` — โหมดผูกเครื่องเดิมสร้างด้วย `requireActivation: true`; เพิ่มเช็คโหมดเริ่มต้น (trial → trial หมดถูกบล็อก, คีย์มั่วถูกปฏิเสธ, คีย์จริง licensed ทันที, อีกเครื่องก็ผ่าน, คีย์หมดอายุหยุดทำงาน, ลบคีย์หลังหมดทดลองถูกบล็อก)
- `test/smoke-license.js` (ใหม่), `test/smoke-platform.js`, `test/smoke.js` — ตรวจหน้าจอทุกสถานะด้วยคู่กุญแจทดสอบ (ไม่ใช้คีย์จริง); เช็ค "คัดลอกรหัสเครื่อง" ถูกแทนที่ด้วยเช็คว่าไม่มีรหัสเครื่องแล้ว
- `renderer/home.html`, `renderer/settings.html` — เพิ่ม padding ปุ่มภาษา/ปุ่มสลับ

**ผลทดสอบ:** `npm test` ผ่านทั้งหมด, smoke 157/157 (ทั้งโค้ดสดและแอปที่แพ็กแล้ว) รวม: ช่วงทดลอง → คีย์มั่วขึ้นข้อความผิดพลาดและยังเป็น trial → คีย์จริงขึ้น Licensed ทันที (หน้าแรกขึ้นชื่อผู้ถือสิทธิ์) → ข้อมูลที่เก็บไว้ใช้ได้บนเครื่องอื่นด้วย → ลบคีย์หลังหมดทดลอง คัดลอก/บันทึกถูกปฏิเสธ

**ยังไม่ได้ตรวจ:** ใช้คีย์จริงของเจ้าของ (ทดสอบด้วยคู่กุญแจจำลองเท่านั้น), ปิด-เปิดแอปจริงจากตัวติดตั้ง (ทดสอบด้วยการสร้าง manager ใหม่จากข้อมูลที่เก็บ), การติดตั้ง/ติดตั้งทับ

**ต้องยอมรับ:** คีย์ 1 ดอกใช้ได้ไม่จำกัดเครื่อง ใครได้คีย์ไปก็ใช้ต่อได้ เพราะไม่มีเซิร์ฟเวอร์ตรวจ เจ้าของรับทราบแล้ว
