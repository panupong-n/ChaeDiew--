คุณคือวิศวกรฝั่ง **Windows (Electron)** ของโปรเจกต์ Tenix-ChaeDiew ตอบและเขียนรายงานเป็น **ภาษาไทย** (ชื่อไฟล์ คำสั่ง โค้ดคงเป็นอังกฤษ)

# งานนี้: เปลี่ยนการเปิดใช้งานเป็น "ใส่คีย์แล้วจบ"
เจ้าของโปรเจกต์อนุมัติแล้ว: ผู้ใช้วางคีย์ `TXCD1-…` แล้วแอปต้องเป็น **Licensed ทันที** ไม่ต้องส่งรหัสเครื่อง (`MC-…`) ไปขอรหัสเปิดใช้งาน (`TXAC1-…`) เพราะไม่มีเซิร์ฟเวอร์ และใช้ในทีมภายในเท่านั้น ฝั่ง Mac (Swift) แก้เสร็จและผ่านเทสต์แล้ว ฝั่ง Windows ต้องทำให้ตรงกัน

# ข้อสำคัญ: ห้ามเขียนทับไฟล์ที่คุณแก้ไว้
ฝั่ง Windows แก้ `electron/` ไปมากแล้วและเจ้าของพอใจ **ห้ามคัดลอกโฟลเดอร์ `electron/` จาก Mac มาทับ** ให้แก้เฉพาะจุดด้านล่างในไฟล์ปัจจุบันของคุณ (ถ้าโค้ดของคุณต่างจากตัวอย่างด้านล่าง ให้ปรับตามโครงสร้างจริง แต่ผลลัพธ์ต้องเหมือนกัน) ห้ามเปลี่ยนรูปแบบคีย์/รหัส และห้ามแตะ `src/public-key.js`

# สิ่งที่ต้องแก้ (ทำทีละข้อ แล้วรัน `npm test` กับ smoke)
1. **`electron/src/license.js` — class `LicenseManager`**
   - ให้ constructor รับตัวเลือก `requireActivation` (ค่าเริ่มต้น `false`) เก็บเป็น `this.requireActivation`
   - ใน `status()` หลัง `verifyKey(...)` ผ่าน (ลายเซ็นถูก ยังไม่หมดอายุ) ให้ `if (!this.requireActivation) return { state: 'licensed', info, allowsUse: true };` **ก่อน** บล็อกตรวจรหัสเปิดใช้งาน ส่วนที่เหลือ (needsActivation ฯลฯ) คงไว้เผื่อกลับไปใช้โหมดผูกเครื่อง
   - `activate()` ยังรับ `TXAC1-…` ได้เหมือนเดิม แต่ไม่จำเป็นต้องใช้
   - **`src/main.js` ไม่ต้องส่ง `requireActivation`** (ใช้ค่าเริ่มต้น false) ถ้าคุณสร้าง manager ด้วย `requireActivation: false` อยู่แล้วก็ใช้ได้ ผลเท่ากัน
2. **หน้าไลเซนส์ `renderer/license.html` + `renderer/license.js`** (ปรับตามโครงของคุณ)
   - สถานะ **Licensed**: ซ่อนช่องกรอก ปุ่ม Activate และ Paste เหลือเฉพาะปุ่ม "ลบไลเซนส์" และรายละเอียด (ออกให้แก่, หมดอายุ, รหัสคีย์) **ไม่แสดงแถว "จำนวนเครื่อง (Seats)"** (ไม่ได้บังคับแล้ว) และไม่แสดงรหัสเครื่อง
   - สถานะ **ทดลอง/หมดทดลอง**: ไม่ต้องแสดงรหัสเครื่องแล้ว ช่องกรอกเปลี่ยนป้ายเป็น "คีย์ไลเซนส์" (placeholder `TXCD1-…`)
   - สถานะ "needsActivation" (ถ้ายังเก็บไว้): ไม่แสดงบรรทัด Free trial
   - ข้อความหลังกดเปิดใช้งาน: ถ้า state เป็น licensed ให้แสดง "เปิดใช้งานสำหรับ %@ แล้ว"
   - เพิ่ม/ตรวจ `src/strings.js` ให้มีคำแปลไทยของ `'License key': 'คีย์ไลเซนส์'` โดยห้ามมี key ซ้ำ
   - หน้าแรก (`home.js`) สถานะบรรทัดล่างต้องขึ้น "ออกให้แก่: <ชื่อ>" เมื่อ Licensed
3. **เทสต์**
   - `test/license.test.js`: ตัวที่ทดสอบ flow รหัสเปิดใช้งานให้สร้าง manager ด้วย `requireActivation: true` เพิ่มเทสต์โหมดเริ่มต้น: ไม่มีคีย์ → trial; trial หมด → บล็อก; คีย์มั่ว → ถูกปฏิเสธ; คีย์จริง → `licensed` ทันที; คีย์เดียวกันบนอีกเครื่อง (machineId ต่าง) ก็ผ่าน; คีย์หมดอายุ → หยุดทำงาน
   - smoke (`test/smoke.js` / `test/smoke-license.js` ของคุณ): ปรับให้ตรงว่าคีย์จริงที่ผ่านลายเซ็นเป็น `licensed` ทันที และเมื่อลบคีย์หลังหมดทดลอง การคัดลอก/บันทึกต้องถูกปฏิเสธ (หน้าต่างไลเซนส์ขึ้น)
4. **เอกสาร**: ใน `docs/LICENSING.md` ระบุว่าโหมดที่ส่งมอบคือ "คีย์ถูกต้อง = ใช้ได้เลย" (seats เป็นข้อมูลเฉยๆ คีย์ 1 ดอกใช้กี่เครื่องก็ได้) ส่วนโหมดผูกเครื่องปิดไว้ (`requireActivation: true`)

# เกณฑ์ที่ต้องผ่านก่อนรายงานว่าเสร็จ
- `npm test` ผ่านทั้งหมด และ `npx electron . --smoke out` ผ่านทั้งหมด (รายงานจำนวนจริง ถ้าล้มให้แสดงผลลัพธ์)
- ทดสอบบน Windows จริง: ใส่คีย์ที่ออกจากระบบ (ชื่อเช่น "Tenix #02") ในหน้าไลเซนส์ → ขึ้น "มีไลเซนส์แล้ว" ทันที ไม่มีช่องกรอก แล้วปุ่ม คัดลอก/บันทึก ใช้ได้หลังปิด-เปิดแอปใหม่ (ข้อมูลเก็บผ่าน `safeStorage`/DPAPI)
- ใส่คีย์ปลอม/ตัดตัวอักษร → ขึ้นข้อความผิดพลาดภาษาไทย ไม่ crash
- แนบภาพหน้าจอหน้าไลเซนส์สถานะ Licensed และสถานะทดลอง และสรุปไฟล์ที่แก้ (ไฟล์:ส่วน) ใน `docs/WINDOWS-TEST-REPORT.md` เป็นภาษาไทย
- สร้างตัวติดตั้งใหม่ (`npm run dist:win`) แล้วทดสอบเส้นทางนี้จากตัวติดตั้งจริงอีกครั้ง
